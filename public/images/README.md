# Project Images

Place your actual project photographs in this folder.

## Required Images

### Hero & General
- `hero-bg.jpg` — Full-screen hero background (recommended: 1920×1080px, architectural/construction site)
- `hero-visual.jpg` — Right-column hero panel image (recommended: 800×1000px, construction project or villa)
- `about-main.jpg` — About section main photo (recommended: 600×750px, team or project)
- `about-accent.jpg` — About section accent photo (recommended: 400×400px)
- `og-image.jpg` — Social media share image (1200×630px)

### Commercial Projects
- `commercial-1.jpg` — Corporate office or commercial building
- `commercial-2.jpg` — Industrial or warehouse project

### Residential Projects
- `residential-1.jpg` — Apartment or housing complex
- `residential-2.jpg` — Townhouse or residential colony

### Private / Villa Projects
- `villa-1.jpg` — Luxury villa exterior or interior
- `villa-2.jpg` — Duplex or premium home

## Image Recommendations
- Use JPG format for photographs (quality 80-85%)
- Use WebP where possible for better performance
- Recommended max file size: 300KB per image
- Provide good alt text (already set in components)

## Fallback
If an image is not found, the website falls back to a tasteful Unsplash stock photo
so the layout never breaks. Replace these with real project photos before going live.
